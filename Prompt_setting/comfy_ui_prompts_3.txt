# Comfy-UI 提示词集合：游戏模拟与叙事体验

## 总体主题提示词

```
An immersive gaming perspective where reality and virtual worlds merge. Player's interaction with digital environments creates narrative paths, enhanced by cinematic lighting. 8K photorealistic detail with clear focus in the middle, ray traced reflections showing the boundary between real and virtual experience
```

## 如何在Comfy-UI中使用
1. 复制适合您的提示词
2. 将其粘贴到Comfy-UI的文本提示输入字段中
3. 根据需要调整权重和其他参数
4. 可以将正面提示词与负面提示词组合使用以获得更精确的结果
