# 六边形房屋生成器

这是一个Blender插件，用于生成六边形房屋结构阵列。

## 项目结构

```
hexagonal_housing/
│
├── __init__.py          # 插件初始化和注册
├── operator.py          # 操作器类定义
├── panel.py            # UI面板类定义
├── hexagon.py          # 六边形房屋生成逻辑
├── channel.py          # 通道生成逻辑
├── materials.py        # 材质处理逻辑
├── utils.py            # 工具函数
└── README.md           # 项目说明文档
```

## 功能说明

- 生成六边形房屋阵列
- 可调整行数、列数和高度
- 支持添加窗户、内部网格和灯光效果
- 房屋之间通过通道连接
- 可设置生成数量

## 使用方法

1. 在Blender中安装插件
2. 在3D视图的侧边栏中找到"六边形房屋"面板
3. 设置参数（行数、列数、高度等）
4. 点击"生成六边形房屋阵列"按钮

## 参数说明

- 行数：阵列中的行数（1-50）
- 列数：阵列中的列数（1-50）
- 高度：六边形房屋的高度（0.1-10.0）
- 生成数量：要生成的阵列数量（1-100）
